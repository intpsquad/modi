# 팀과 역할

이 문서가 있는 이유: `docs/backend/*-handoff.md` 들이 **"대상: `ActivityService` 담당자"** 처럼
역할로만 지칭하는데, 그게 누구인지 적힌 곳이 저장소 어디에도 없었다(2026-08-13 신설).

| 이름 | 역할 | 주로 만지는 곳 |
|---|---|---|
| 윤주하 | 프론트 (Flutter) | `app/` |
| 김예원 | 프론트 (Flutter) | `app/` |
| 박민영 | 백엔드 (Spring) | `server/` |
| 김주우 | 인프라 · 배포 · AI 서버 | `deploy/`, `.github/workflows/`, `ai/` |

**프론트는 두 명이다.** 핸드오프 문서에서 "프론트 담당자"를 단수로 쓰지 말고, 화면 단위로
누가 맡았는지 그 문서에 적는다.

> **새로 들어온 사람에게 보낼 것**: [`docs/team-access-setup.md`](./team-access-setup.md) —
> SSH 키 등록 · 오라클 콘솔 초대 · Tailscale · 가비아 DNS · Apple Developer · 저장소 remote 교체를
> 한 문서에 모았다. 그대로 복사해 보낼 수 있게 썼다.

## 이 문서를 고쳐야 하는 때

- 사람이 들어오거나 나갈 때
- 역할이 바뀔 때 — 특히 **인프라**는 서버 접근 권한(`ssh modi`)·GitHub Secrets·Apple Developer
  계정·가비아 DNS 를 쥐고 있어, 인계 없이 바뀌면 배포가 막힌다
- 새 핸드오프 문서를 쓸 때: 역할 이름만 쓰지 말고 이 표를 참고해 사람을 지목한다

## 한 사람만 가진 것 (버스 팩터 1)

인계가 없으면 그 기능이 그대로 멈추는 것들이다. **아래는 채워 넣어야 한다** —
지금은 김주우 한 명에게 몰려 있다.

| 자산 | 지금 가진 사람 | 나눠 가져야 하는 이유 |
|---|---|---|
| 오라클 서버 SSH 키 (`~/.ssh/oracle`) | 김주우 | 없으면 배포·롤백·로그 확인이 전부 막힌다 |
| Tailscale 계정 (서버 접속 경로) | 김주우 | 공인 IP:22 가 막힌 네트워크에서는 유일한 경로다 |
| GitHub 저장소 관리자 | 김주우 | Secrets·브랜치 보호·가시성 변경 |
| OpenAI 플랫폼 계정 (결제) | 김주우 | 키가 만료·한도 초과되면 AI 3기능이 조용히 꺼진다 |
| 가비아 도메인 (`maramodi.cloud`) | **미확인** | DNS 전환·갱신. 누가 결제했는지 확인이 필요하다 |
| Apple Developer 계정 | 미구매 | iOS 전용 출시라 이게 없으면 배포 경로가 0이다 |
