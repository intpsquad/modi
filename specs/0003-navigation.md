## 하위 페이지 규칙 (2026-08-05 확정)
탭 루트(위 4개)가 아닌 모든 화면은 **하위 페이지**다. 아래 4개를 전부 만족해야 한다.

| 규칙 | 내용 | 구현 |
|------|------|------|
| 네비바 없음 | 탭이 아니라 새 페이지이므로 하단 네비바가 보이지 않는다 | 루트 네비게이터에 push — 셸 브랜치 안에 중첩하는 라우트에는 `parentNavigatorKey: rootNavigatorKey`(`routing/app_router.dart`)를 붙인다. `/mypage/*`(설정 하위)·`/todos/item/:id`·`/archive/item/:id`가 이 방식. 셸 밖 최상위 라우트(`/member/:userId`, `/room/*`, `/legal`)는 이미 만족 |

> **예외 — `/archive/folder/:id`(폴더 자료 목록)는 네비바를 유지한다**(2026-08-08 요청). 모아보기는 "폴더 선택 → 자료 선택 → 자료 본문"으로 파고드는데, 자료 선택 화면까지는 탭 이동이 자연스러워 네비바가 있어야 한다는 사용자 확정. 그래서 이 라우트만 **`parentNavigatorKey`를 붙이지 않아 셸 브랜치 네비게이터에 남긴다**(네비바 노출). 몰입이 필요한 **자료 본문 `item/:id`은 그대로 루트 push(네비바 숨김)**. 회귀 테스트가 이 예외를 명시적으로 검사한다.
| 진입 방향 | 오른쪽에서 왼쪽으로 밀려 들어온다 | `design/theme.dart`의 `pageTransitionsTheme` — **모든 플랫폼**에 `CupertinoPageTransitionsBuilder` |
| 뒤로가기 아이콘 | `←`가 아니라 **`<`**(chevron) | 같은 파일 `actionIconTheme.backButtonIconBuilder` = `Icons.chevron_left`(28). 커스텀 앱바를 직접 그리는 화면(`archive_item_detail_screen.dart`, `signup_screen.dart`)도 같은 아이콘을 쓴다 |
| 엣지 백 제스처 | 화면 **왼쪽 끝**을 잡고 오른쪽으로 끌면 이전 화면이 드러난다 | Cupertino 전환 빌더가 함께 제공(안드로이드 기본 Zoom/PredictiveBack에는 없어 플랫폼 구분 없이 적용) |

> 회귀 테스트: `app/test/routing/subpage_navigation_test.dart` — 셸에 중첩된 라우트의 `parentNavigatorKey`를 **전수 검사**하므로 새 하위 페이지를 브랜치 안에 잘못 넣으면 바로 실패한다.

## 재진입 리다이렉트 로직 (go_router redirect)
```
미인증                         → /onboarding/intro
인증 + 방 소속 0개             → /onboarding/room-setup  (게이트: 셸 접근 불가)
인증 + 방 있음:
  마지막 본 방 ACTIVE          → /home (그 방)
  마지막 본 방 ENDED:
    다른 ACTIVE 방 有          → 최근 열어본 ACTIVE로 전환 + 안내 토스트 → /home
    ACTIVE 방 無               → /home (S-06 방없음 상태)
```

> **구현 위치(2026-07-27)**: 위 로직은 `go_router`의 `redirect`가 아니라 `RoomSession`(`app/lib/features/room/room_session.dart`, `specs/0008-방-전환.md`)이 홈 화면 `_load()`에서 수행한다. 라우터 `redirect`는 지금도 인증·`membership`(방 소속 0개/있음) 게이팅만 담당하고 어떤 roomId를 열지는 모른다 — `/home`으로 보내면 그 안에서 `RoomSession`이 "마지막 본 방"을 해석해 S-04/S-06을 스스로 분기한다.
