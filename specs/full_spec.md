## 3. 홈 탭

### 3-1. 상단 영역 (공통)

- **방 전환 트리거**: "○○방 이름 ▾" 탭 → 방 전환 바텀시트 오픈 (메인 트리거)
    - 홈 화면 롱프레스 시에도 동일 시트 오픈 (보조 트리거)
    - 우측 상단 햄버거버튼(홈에서만 활성화) → 설정 진입 (현재 방 설정 + 계정 설정)

### 3-2. 콘텐츠 영역 — 진행중인 방 (카드 세로 스택)

1. D-day 카드 — D-day·종료일·진행률 바·완료/전체 개수·'팀 현황' 라벨
2. 멤버 아바타 줄 — 진행률 링 테두리, 진행률 높은 순 좌→우 가로 스크롤, 탭 시 멤버 개인 투두 페이지 이동, 콕찌르기 버튼
3. 주간 캘린더 (이거는 일정과 연동됨, 투두연동 x)
4. 투두 보여주기
    1. 오늘 날짜
    2. 체크박스, 투두제목
    3. 날짜 기준 우선순위
    4. 최대개수 정해서 내 담당 투두만 노출
5. 아카이브 미리보기 — 썸네일 가로 스크롤
    1. 최근 추가된 순으로 정렬
        1. 썸네일, 폴더, 태그 등
        2. 더보기 버튼 누르면 아카이브 탭으로 이동

### 3-3. 콘텐츠 영역 — 종료된 방 (읽기전용 요약형, 레이아웃 전환) (후순위)

```
[최상단] 재시작 버튼
        "○일간의 목표가 끝났어요" + 기간(시작일~종료일)

[카드] 최종 목표 달성 현황 — 완료 항목, 최종 완료율
[카드] 내 활동 요약 — 내가 처리한 투두 개수, 콕찌르기 당한 횟수
[카드] 팀 하이라이트 — 가장 열심히 한 멤버
[카드] 아카이브 하이라이트 — 가장 많이 조회된 링크/텍스트
```

- 재시작 버튼 → **방 수정 페이지**로 이동 (기간 연장, 목표/설명 수정, 기존 멤버 유지) → 저장 시 `진행중` 상태로 복귀

### 3-4. 콘텐츠 영역 — 진행중인 방이 하나도 없을 때 (신규 반영)

- 안내 문구: "방에 들어가거나 생성하세요" (또는 유사 문구)
- CTA 버튼: [방 만들기] / [초대 코드 입력]
- 하단 네비(홈/투두/일정/아카이브)는 그대로 유지

### 3-5. 방 전환 바텀시트

1. 방 목록 (탭 = 즉시 전환, 종료된 방은 "종료됨" 뱃지 표시)
    - 지금 진행중인 목록
    - 종료된 방 목록(이건 얕은 회색 표시로 2~3개정도만 표시되고 아래 …버튼을 누르면 설정 페이지에 있는 지난 방 보기 페이지로 넘어가기)
2. 방 만들기
3. 초대 코드 입력

## 4. 계정 · 앱 재진입 로직

### 4-1. 로그인 및 회원가입 (확정)

- 로그인 수단: **카카오/네이버/구글/애플 소셜 로그인 + 자체 회원가입** 모두 지원
- 수집 정보
    - 자체 가입: 닉네임, 프사(선택), 아이디, 비밀번호
    - 소셜 가입: 별도 추가 입력 없음 (소셜 계정 정보로 대체)
- 개인정보처리방침·이용약관 동의 항목 구성 — 별도 확인 필요

### 4-2. 앱 재진입 시 방 노출 우선순위

```
1순위: 마지막으로 보던 방이 진행중 → 그대로 노출
2순위: 마지막으로 보던 방이 종료됨
       → 진행중인 다른 방 有 → "내가 최근에 열어본 순"으로 자동 전환 + 안내 토스트
       → 진행중인 방 無 → 3순위
3순위: 진행중인 방이 하나도 없음 → 홈 화면에 "방에 들어가거나 생성하세요" 안내 (3-4 참고)
```

### 4-3. 방 종료 조건

- 목표 기간(설정한 기간) 종료 시 **자동으로 종료 처리**

## 5. 투두 탭

- 남의 투두는 홈의 멤버 아바타 탭을 통해 **해당 개인의 투두 페이지로** 별도 이동

### 레이아웃

- todo / done 탭
- 카테고리(상위), 펼치면 하위 ToDo 체크박스(담당자 아바타+체크).
- 기본: 내 투두만 보기
- 다른 팀원 투두 전체 보기 버튼
- 독립 ToDo: 카테고리에 속하지 않는 단독 항목
- 정렬: 등록순 / 완료 항목은 done 탭

### 추가 (바텀시트: 직접추가 / AI추천추가)

- **직접추가**
    - 카테고리 → 이름
    - ToDo → 제목·상세(선택)·담당자 (필수, 미지정 시 본인으로 자동 설정)
- **AI추천추가**
    - AI 로딩 → 후보 목록 (아카이브+목표명+기존 투두 참고, 중복 후보 재노출 안 함).
        - 이미 있는 카테고리에 맞는 투두를 추천
        - 새로 카테고리 + 투두도 추천
        - 이후 추천 중 원하는 거 바로 add ㄱㄱ (대신 담당자는 미지정됨, 나중에 따로 담당자 설정 필요)

### 미지정 처리

- 상단 배너 → 미지정 목록 → 클릭해 채워넣기 (ToDo→담당자)

## 6. 일정 탭

- 월간 그리드 캘린더
- 오늘 일정 목록 카드 형태로 표시
- **일정만 표시 (Todo는 표시 안함)**
- 일정 수정 = 탭 → 수정 바텀시트
- 생성 = 날짜 탭 → 일정 바로 추가

## 7. 아카이브 탭

- 방 단위 공유 폴더 (사용자 정의 이름, [+ 폴더 추가])
- 3뎁스 구조
    1. 폴더 목록
    2. 폴더 내 목록 — 검색·정렬·항목(제목·날짜·출처·썸네일·태그·핀)
    3. 항목 상세 — 순수 정보 뷰 (폴더이동/핀/삭제/좋아요버튼)
- 등록 시 본문 텍스트 확보 + AI 자동 태깅
- 각 항목에 좋아요 달 수 있고, 좋아요 순으로 조회 가능

---

## 8. 멤버 투두 페이지

- **내 투두 확인**은 이 페이지가 아니라 네비바 **투두 탭**(또는 홈 "내 오늘 할 일" 카드)에서 함
- 이 페이지는 **오직 타인의 투두를 조회하기 위한 용도**로만 존재
- 홈의 멤버 아바타 탭 → 진입 (투두 탭과 동일 레이아웃 재사용)
- 체크 불가, **재촉(노크) 버튼만** 제공

## 9. 방 관련 페이지

### 9-1. 방 만들기 페이지

```
방 이름
대표사진 (옵션)
기간
방 목표 (간단)
방 목표 상세설명 (옵션)
        ↓ [만들기]
초대코드 생성 화면 — 코드 표시, 복사 버튼, 외부 공유(카톡/인스타 등)
```

### 9-2. 초대 코드 입력 페이지

```
코드 입력창
[참여하기] 버튼 → oo님의 방 이름에 참여하시겠습나까? -> 방 참여
```

### 9-3. 방 수정 페이지 (종료된 방 재시작 시 진입)

- 기간 연장, 목표/설명 수정, 기존 멤버 유지 → 저장 시 `진행중` 전환

## 10. 설정 페이지

### 계정 (전역)

- 프로필 (닉네임, 프로필 사진 = 멤버 아바타로도 사용)
- 로그인 계정 정보
- 알림 설정 (전체 on/off, 콕찌르기/재촉, 일정 전날/디데이, 방 멤버 입장/퇴장, 내 담당 투두 추가 개별)
- 로그아웃 / 회원 탈퇴

### 현재 방 설정

- 대표이미지·이름·목표·상세설명·기간 변경

### 방 멤버 관리

- 멤버 목록, 초대코드 재발급/공유
- **방장 개념 없음** — 방을 처음 만든 사람도 그냥 멤버 중 한 명일 뿐, 모든 멤버가 동일한 권한을 가짐 (방 삭제 등 모든 액션을 누구나 수행 가능)

### 방 나가기

- 방을 없애는 것이 아니라 지 혼자 나감
- 만약 방에 사람이 1도 없으면 그 방 걍 사라짐

### 지난 방 보기

- 종료된 방들을 아카이브 형식으로 모아보는 리스트
- 항목: 방 이름, 종료일, 진행 기간, 최종 완료율
- 탭 → **종료된 방 요약형 홈(3-3)**으로 진입 (읽기전용 + 재시작 가능)
- 진행중 방이 있어도 언제든 여기서 확인 가능

### 앱 전체

- 버전 정보, 약관/정책, 문의하기

## 12. 데이터 모델 요약

- **ToDo** (하위 또는 독립): 마감 無 / 담당자 복수 가능 / 완료·미완료 체크
- **진행률** = (완료 ToDo) / (전체 ToDo)
- **개인 진행률** = 본인 담당 ToDo 기준
- **방 상태**: `진행중` / `종료(읽기전용)` — 기간 만료 시 자동 전환

## 13. 전체 페이지 목록 (개발 체크리스트용)

```
스플래시 (보류)

온보딩 (필수 3단계, 스킵 불가)
 ├ 서비스 소개 (캐러셀)
 ├ 회원가입/로그인
 └ 방 만들기 / 초대코드 입력

홈 탭
 ├ 진행중인 방 홈 대시보드 (D-day, 아바타줄, 주간캘린더, 오늘투두, 아카이브미리보기)
 ├ 종료된 방 요약형 홈 (후순위)
 ├ 진행중인 방 없음 안내 화면 ("방에 들어가거나 생성하세요" + CTA 2개)  ← 신규
 └ 방 전환 바텀시트

투두 탭
 ├ 투두 목록 (todo/done 탭, 카테고리+하위ToDo, 독립ToDo, 내투두/전체보기 토글)
 ├ 추가 바텀시트
 │   ├ 직접추가 (카테고리 생성 / ToDo 생성)
 │   └ AI추천추가 (로딩 → 후보리스트 → Add)
 └ 미지정 처리 화면 (담당자 채우기)

일정 탭
 ├ 월간 캘린더 + 오늘 일정 카드
 ├ 일정 수정 바텀시트
 └ 일정 생성 (날짜 탭 → 바로 추가)

아카이브 탭
 ├ 폴더 목록
 ├ 폴더 내 목록 (검색/정렬)
 ├ 항목 상세 (폴더이동/핀/삭제/좋아요)
 └ 자료 등록 화면 (링크/텍스트 등록 → AI 자동 태깅)

멤버 투두 페이지 (타인 조회 전용, 재촉만 가능)

방 관련
 ├ 방 만들기 페이지 (+ 초대코드 생성/공유 화면)
 ├ 초대 코드 입력 페이지 (+ "참여하시겠습니까?" 확인 모달)
 └ 방 수정 페이지 (재시작용)

설정 페이지
 ├ 프로필 수정
 ├ 알림 설정
 ├ 현재 방 설정 (이미지/이름/목표/설명/기간)
 ├ 방 멤버 관리 (목록, 초대코드 재발급/공유)
 ├ 방 나가기 (확인 모달, 마지막 인원이면 방 자동 삭제 안내)
 ├ 지난 방 보기 (종료된 방 리스트 → 종료방 요약홈으로 진입)
 └ 앱 전체 정보 (버전/약관/문의)
```

- 추가사항(참고용)
    - 카테고리(행사/여행/스터디 등) 선택 단계는 **사용하지 않기로 확정**. 사용자가 자유롭게 이름/목표/설명만 입력.
    - 정산·투표 기능은 팀 회의에서 스코프 제외로 확정 — 4~5주 개발 기간 내 핵심 학습목표(RAG/트랜잭션/동시성/Jira)와 직결되는 기능에 집중하기 위함
        - 팀 회의에서 4~5주 개발 기간 내 우선순위 재검토 후 **정산/투표 기능 전체를 이번 스코프에서 제외**하기로 확정
        - 홈 카드 스택, 아카이브 연동, 웬투밋 스타일 투표 등 이전에 설계했던 상세 스펙은 모두 폐기
        - 추후 여유가 생기면 별도 기능으로 재검토 가능하나, 현재 IA/UI 설계에는 반영하지 않음
