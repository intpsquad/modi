# CLAUDE.md — `ai/` (FastAPI AI 서버)

> 이 문서는 **`ai/` 안에서 작업할 때의 규칙**만 다룬다.
> 프로젝트 전체 규칙·아키텍처·데이터 모델의 단일 진실은 루트 [`CLAUDE.md`](../CLAUDE.md)와 [`specs/`](../specs)에 있다.
> **여기서 스펙을 복제하지 않는다** — 충돌하면 루트가 이긴다.

## 이 서버의 위치

이 서버는 **투두 추천(S-16-B) 전용**이다. 아카이브 자동 태깅(S-25-C)은 **Spring이 직접 처리**한다(`docs/DECISIONS.md` 확정, 2026-07-28).

```
투두 추천   앱(Flutter) → 서버(Spring) → AI 서버(FastAPI) → OpenAI(게이트웨이 프록시)
자동 태깅   앱(Flutter) → 서버(Spring) ───────────────────→ OpenAI(게이트웨이 프록시)
                                        ↑ 이 서버를 거치지 않는다
```

- 앱은 이 서버를 **직접 호출하지 않는다.** Spring의 요청만 받는다.
- 원본 데이터(자료·폴더·태그·투두·방)의 주인은 **Spring + PostgreSQL**이다. 이 서버는 도메인 DB의 주인이 아니다.
- 외부에 포트를 열지 않는다. Docker 내부 네트워크에서 Spring만 호출한다.

## 명령

```bash
uv sync                                            # 의존성 설치 (가상환경 자동 생성)
uv run uvicorn modi_ai.main:app --reload --port 8000
uv run pytest                                      # 테스트
uv run ruff check .                                # 린트
uv run ruff format .                               # 포맷
```

커밋 전 게이트는 **`uv run ruff format --check . && uv run ruff check . && uv run pytest`** 세 개다.
CI(`.github/workflows/ci.yml`)의 `ai` 잡(경로 필터 `ai/**`)이 같은 것을 돈다 — 앞에 `uv sync --frozen`이 붙으므로
`pyproject.toml`을 고치고 `uv.lock`을 커밋하지 않으면 CI에서 실패한다.

## 규칙

- **한 번에 얇게 한 줄.** 각 단계는 독립적으로 동작·데모 가능해야 한다. 여러 기능을 한 커밋에 넣지 않는다.
- **프롬프트 변경은 평가셋으로 검증한다.** 규칙을 하나 추가해 한 케이스를 잡으려다 다른 케이스를 깨뜨린 전례가 실측으로 있다([`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md) 참조). 눈으로 좋아 보인다는 이유로 프롬프트를 바꾸지 않는다.
- **"됐다" 금지** — 테스트 출력·응답 본문 등 증거를 제시한다(루트 CLAUDE.md 공통).
- **지표를 먼저 만들고 데이터를 맞추지 않는다.** 프로토타입에서 자동 채점층을 이식해 지표 셋을 먼저 만들었다가 **셋 다 무효로 판명돼 전부 지웠다**([`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md) "다시 하지 말 것"). 순서는 **실제 모델 출력을 눈으로 보고 → 무엇이 문제인지 찾고 → 그것을 재는 지표를 정의**한다.
- **라벨의 뜻을 다른 질문에 갖다 쓰지 않는다.** `has_actionable_content`는 태깅용("태그로 달 구체적 장소명이 있나")인데 추천 판정("침묵해야 하나")에 써서 잘못된 결론을 냈다. 라벨을 재사용하기 전에 그 라벨이 **어떤 질문에 답하려고 만들어졌는지** 확인한다.
- **모델·프롬프트를 바꾸면 [`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md)에 측정 결과를 남긴다.** 근거 없는 교체 금지.
- **추측 금지.** 스펙에 없거나 모순되는 결정은 [`docs/DECISIONS.md`](docs/DECISIONS.md)의 "미확정"에 적고, 그 항목에 의존하는 구현 전에 사용자에게 확인받는다.

## 하지 말 것

- **태깅 기능 구현** — 태깅은 Spring 담당이다(`docs/DECISIONS.md` 확정). 여기에 만들지 않는다.
- **`langchain` 풀 패키지 설치** — 쓰는 것은 **`langchain-core` + `langchain-openai`** 둘뿐이고, 풀 패키지는 그 밖의 것까지 끌고 온다. *(2026-08-01~2026-10-18 에는 `langgraph` 도 의도적으로 넣었다가 걷어냈다 — 아래 참고.)*
- **LangSmith Prompt Hub를 프롬프트의 진실로 삼기** — 원본은 git에 둔다. UI에서 편집한 것을 런타임이 당겨가면 평가셋 게이트가 무력화된다.
- **입력 전처리 되살리기** — 프로토타입의 `preprocess.py`는 폐기됐다. OpenAI에서는 **결과가 악화**되고, 여러 어절 상호명을 쪼개 없는 가게를 만들어낸다(`삶은 감자` → `삶은`/`감자`). 상세는 [`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md) "다시 하지 말 것".
- **Kiwi 자동 채점층 되살리기** — 2026-07-30에 전면 삭제했다. 되살리기 전에 위 "다시 하지 말 것"을 먼저 읽을 것 — 원문 포함 검사는 구조적으로 헛경보를 내고, 고유명사 손상 탐지는 우리 모델에서 잡을 게 없었다.
- **이미지 OCR** — 스크린샷은 참고자료로만 저장한다.
- **자료의 폴더 자동 분류** — 폴더는 사용자 몫, AI는 태그만 단다.
- **AI 가 카테고리를 정하게 되살리기** — 2026-08-04에 **기능을 통째로 걷어냈다.** 후보는 카테고리 없이 나가고(= 기타) 사용자가 투두 탭에서 직접 분류한다(채택 → 기타 → 편집 시트에서 선택. **드래그 UI 는 아직 없다**). 세 방법을 만들어보고 셋 다 실패했다: 프롬프트로 시키기([`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md) #21) · 임베딩 코사인(실사용 10/10 실패) · LLM 별도 호출(#31, 후보당 카테고리 종수 0.81 → 0.96 **악화**). ⚠️ **셋째는 비싸서가 아니라 효과가 없어서 기각이다** — 지연은 오히려 괜찮았다. 되살리기 전에 반드시 [`docs/RESTORE-category-assignment.md`](docs/RESTORE-category-assignment.md) 를 읽을 것. `git revert` 한 번이면 코드는 돌아오지만 **실패한 상태로 돌아간다.**
- **투두 추천의 증분 생성** — 새 자료만 처리하지 않고 매번 전체를 다시 본다.
- **후보 채택 시 담당자 자동 지정** — 미지정으로 생성한다.
- **추론(reasoning) 모델을 근거 없이 배제하거나 채택하기** — 속도만 보고 정하지 않는다. ~~`nano`류는 느리고 숨은 토큰을 태우지만 **크레딧 단가는 훨씬 싸다**~~ → **2026-08-13: 이 반대 논거가 사라졌다.** 게이트웨이 키 회수로 제공사가 OpenAI 직접이 되면서 **크레딧 등급이라는 축 자체가 없어졌고**, 직접 과금에서는 숨은 추론 토큰이 **출력 토큰 요금으로 그대로 청구**된다 — 이제 추론 모델은 느린 쪽이면서 동시에 비싼 쪽이다. ~~추천 모델은 착수 전 평가셋으로 품질·토큰·크레딧을 함께 재고 정한다(미확정)~~ → **2026-08-02 닫혔다**: 추천은 `gpt-5.4-nano`로 확정되고 시간·비용·품질 세 축이 사후에 뒷받침됐다(`docs/DECISIONS.md`). **태깅(Spring)도 2026-08-13에 `gpt-5.4-nano`로 합쳤다** — 태깅 워크로드에서 `gpt-5-nano`는 completion의 92.7~98.6%를 숨은 추론에 썼고 같은 입력이 4.41초↔15.43초로 튀었다(`docs/EXPERIMENTS.md` #34). **원칙 자체는 유효하다** — 다음에 모델을 바꿀 때도 축을 함께 재고 `docs/EXPERIMENTS.md`에 남긴다. 단 **비용 축은 이제 크레딧이 아니라 달러·출력 토큰으로 잰다.**
- **투두 추천에 그래프·검수·임베딩 중복 거르기를 되살리기** — **2026-10-18 에 걷어냈다**(#109, 사용자 확정: 시연용으로 "1회 LLM 호출"). 추천은 `자료 고르기 → LLM 1회 → 문자열 필터` 의 직선 함수다(`src/modi_ai/suggest.py`). 되살리기 전에 `docs/DECISIONS.md` 의 해당 항목을 먼저 읽을 것 — 요지:
  - **LangGraph**(2026-08-01 도입)는 **기능 이득이 0**이었다. 팀 역량·포트폴리오 판단으로 넣었고, 그래프여야만 했던 되돌아가기 루프는 재보고 껐다(#29). "LangGraph 덕분에 좋아졌다"는 사실이 아니었다.
  - **검수(critique)** 는 품질을 올렸지만(부산 메타 행위 40% → 0~6%, #28) 한 배치를 전멸시켜 **빈 화면**을 냈다 — 심사 직전 데모에서 두 번 연속. 2026-08-14 에 껐다. 후보 번호를 `0` 부터 매기면 판정이 밀리는 문제도 있었다(#30, `1` 부터면 30/30).
  - **임베딩 의미 중복 거르기**는 짧은 한국어 제목에서 **라이브 중복 8건 중 3건만** 잡았다(임계값 0.65, #17). 지금은 같은 묶음에 비슷한 후보가 가끔 같이 나온다 — 알고 받은 대가다.
- **운영 환경에서 LangSmith 켜기** — 사용자 자료 본문이 외부 SaaS로 전송된다.
- **도메인 DB 직접 접근** — 필요한 데이터는 Spring이 요청에 실어 보낸다.
- **키를 코드·문서에 적기** — `.env`에만 둔다. `.env.example`에는 이름만.

## 로컬 전용 파일

`ai/.env` — `.env.example`을 복사해 값을 채운다. 새 키가 생기면 **그 즉시 루트 [`README.md`](../README.md)의 "로컬 전용 파일" 절에 파일명·용도·발급 방법을 추가**한다(루트 CLAUDE.md 규칙). 값 자체는 절대 기록하지 않는다.
