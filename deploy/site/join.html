방에 초대받았어요

모디(MODI)는 방을 만들어 팀이 목표 기간 동안 투두·일정·자료를 공유하고 서로 독려하는 협업 앱입니다.

초대 코드

주소에 초대 코드가 없어요. 초대한 분에게 코드를 다시 받아 주세요.

앱에서 열기 앱 설치하기

앱에서 직접 입력하려면

  1. 모디(MODI) 앱을 엽니다.
  2. 초대코드로 참여하기(방이 있으면 방 이름을 눌러 초대코드로 입장하기)를 누릅니다.
  3. 초대 코드 입력 화면에 위 코드를 붙여넣고 참여하기를 누릅니다.
